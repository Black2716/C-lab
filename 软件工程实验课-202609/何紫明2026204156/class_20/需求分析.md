# 需求分析

## 1. 项目背景

本项目是一个命令行任务管理系统，目标是帮助用户高效管理待办事项，支持添加、查看、完成和删除任务，并在程序退出后保留数据，避免任务丢失。

## 2. 业务目标

- 用户可以通过命令快速新增任务。
- 用户可以查看全部任务及当前状态。
- 用户可以完成指定编号的任务。
- 用户可以删除指定编号的任务。
- 程序应在重启后继续保留任务信息。

## 3. 功能需求

### 3.1 添加任务

输入示例：

```bash
todo add "学习C语言"
```

功能：

- 创建新的任务记录。
- 自动生成唯一任务编号。
- 任务默认状态为未完成。

### 3.2 查看任务

输入示例：

```bash
todo list
```

功能：

- 输出任务编号、状态和内容。
- 便于用户快速确认待办事项。

### 3.3 完成任务

输入示例：

```bash
todo done 1
```

功能：

- 将指定编号任务状态更新为已完成。
- 允许用户跟踪任务进度。

### 3.4 删除任务

输入示例：

```bash
todo delete 2
```

功能：

- 删除指定任务。
- 删除后任务编号自动重新排序，保证列表连续。

### 3.5 数据持久化

功能：

- 任务数据写入磁盘文件。
- 程序再次启动时重新加载数据。
- 即使退出程序，任务也不会丢失。

## 4. 非功能需求

- 命令行界面简单清晰，适合终端操作。
- 程序必须响应快速，数据量通常不大。
- 程序需要具备基本错误处理能力。
- 源代码应结构清晰，便于后续扩展。

## 5. 模块设计

```text
+-------------------+
|      main()       |
+-------------------+
         |
         v
+-------------------+     +--------------------+
|  parse command    | --> |  task manager      |
+-------------------+     +--------------------+
         |                     |
         v                     v
+-------------------+     +--------------------+
| load/save file    |     | add/list/done      |
+-------------------+     | delete tasks       |
                         +--------------------+
```

### 5.1 模块职责

- `main()`：负责启动程序，并分发命令。
- `load_tasks()`：从磁盘加载任务。
- `save_tasks()`：将任务写回文件。
- `add_task()`：添加任务。
- `list_tasks()`：显示任务列表。
- `mark_done()`：完成任务。
- `delete_task()`：删除任务。

## 6. 接口设计

```c
int add_task(TaskList *list, const char *content);
int list_tasks(const TaskList *list);
int mark_done(TaskList *list, int id);
int delete_task(TaskList *list, int id);
int load_tasks(TaskList *list, const char *path);
int save_tasks(const TaskList *list, const char *path);
```

这些接口实现了任务生命周期管理，保证代码可维护性。

## 7. 预期结果

程序最终应具备如下能力：

- 支持命令行任务管理；
- 支持任务增删改查；
- 能在程序重启后保留任务；
- 可通过编译和命令测试验证功能正确性。
