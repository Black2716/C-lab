# 按函数调用顺序讲解程序运行过程（执行流程图版）

## 1. 总体调用关系

```mermaid
flowchart TD
    A["main()"] --> B["init_list(&list)"]
    B --> C["load_students(&list, DATA_FILE)"]
    C --> D{"读取成功？"}
    D -- 否 --> E["free_list(&list)"]
    E --> F["EXIT_FAILURE"]
    D -- 是 --> G["print_menu()"]
    G --> H["read_int(请选择操作)"]
    H --> I{"菜单选项"}
    I -- 1 --> J["add_student(&list)"]
    I -- 2 --> K["delete_student(&list)"]
    I -- 3 --> L["modify_score(&list)"]
    I -- 4 --> M["query_student(&list)"]
    I -- 5 --> N["show_students(&list)"]
    I -- 6 --> O["sort_students(&list)"]
    I -- 7 --> P["save_students(&list, DATA_FILE)"]
    I -- 8 --> Q["free_list + init_list + load_students"]
    I -- 0 --> R["save_students"]
    R --> S["free_list(&list)"]
    S --> T["EXIT_SUCCESS"]
    J --> G
    K --> G
    L --> G
    M --> G
    N --> G
    O --> G
    P --> G
    Q --> G
    I -- 其他 --> U["提示无效选项"]
    U --> G
```

## 2. 程序启动阶段

1. 操作系统调用 `main()`。
2. `main` 声明 `StudentList list`。
3. 调用 `init_list(&list)`：
   - `items = NULL`
   - `count = 0`
   - `capacity = 0`
4. 调用 `load_students(&list, "student.dat")`。
5. `load_students` 调用 `fopen`：
   - 如果文件不存在，返回成功，表示首次运行；
   - 如果文件存在，循环调用 `fread`。
6. 每读取一个学生，就调用 `ensure_capacity`：
   - 第一次扩容到 8 个元素；
   - 容量不足时扩大为原来的 2 倍。
7. 文件读取结束后关闭文件，返回 `main`。
8. `main` 输出当前记录数，进入菜单循环。

## 3. 菜单循环流程

```mermaid
flowchart TD
    A["开始循环"] --> B["print_menu()"]
    B --> C["read_int()"]
    C --> D{"整数输入成功？"}
    D -- 否 --> A
    D -- 是 --> E{"choice"}
    E -- 1 --> F["添加学生"]
    E -- 2 --> G["删除学生"]
    E -- 3 --> H["修改成绩"]
    E -- 4 --> I["查询学生"]
    E -- 5 --> J["显示全部"]
    E -- 6 --> K["成绩排序"]
    E -- 7 --> L["保存数据"]
    E -- 8 --> M["重新读取数据"]
    E -- 0 --> N["保存并退出"]
    E -- 其他 --> O["提示无效"]
    F --> A
    G --> A
    H --> A
    I --> A
    J --> A
    K --> A
    L --> A
    M --> A
    O --> A
```

## 4. 添加学生的调用顺序

```mermaid
flowchart TD
    A["add_student"] --> B["read_int(学号)"]
    B --> C{"输入成功？"}
    C -- 否 --> Z["返回菜单"]
    C -- 是 --> D["find_student"]
    D --> E{"学号重复？"}
    E -- 是 --> Z
    E -- 否 --> F["read_line(姓名)"]
    F --> G{"姓名有效？"}
    G -- 否 --> Z
    G -- 是 --> H["read_score(成绩)"]
    H --> I{"成绩有效？"}
    I -- 否 --> Z
    I -- 是 --> J["ensure_capacity"]
    J --> K{"内存成功？"}
    K -- 否 --> Z
    K -- 是 --> L["写入 items[count]"]
    L --> M["count++"]
    M --> N["输出添加成功"]
    N --> Z
```

### 添加过程说明

`main` 选择 1 后调用 `add_student`。该函数依次调用 `read_int`、`find_student`、`read_line`、`read_score` 和 `ensure_capacity`。所有输入和内存检查通过后，才把局部变量 `student` 复制到动态数组末尾。

## 5. 删除学生的调用顺序

```mermaid
flowchart TD
    A["delete_student"] --> B["read_int(学号)"]
    B --> C["find_student"]
    C --> D{"找到学生？"}
    D -- 否 --> E["提示未找到并返回"]
    D -- 是 --> F["memmove 移动后续记录"]
    F --> G["count--"]
    G --> H["提示删除成功"]
    H --> I["返回菜单"]
```

删除不会重新分配数组，而是把目标元素后面的记录整体前移，最后将 `count` 减一。

## 6. 查询学生的调用顺序

```mermaid
flowchart TD
    A["query_student"] --> B["read_int(学号)"]
    B --> C["find_student"]
    C --> D{"找到学生？"}
    D -- 否 --> E["提示未找到"]
    D -- 是 --> F["输出表头"]
    F --> G["print_student"]
    E --> H["返回菜单"]
    G --> H
```

`query_student` 只读取和显示数据，不改变列表内容。

## 7. 修改成绩的调用顺序

```mermaid
flowchart TD
    A["modify_score"] --> B["read_int(学号)"]
    B --> C["find_student"]
    C --> D{"找到学生？"}
    D -- 否 --> E["提示未找到并返回"]
    D -- 是 --> F["read_score(新成绩)"]
    F --> G{"成绩有效？"}
    G -- 否 --> E
    G -- 是 --> H["items[index].score = score"]
    H --> I["提示修改成功"]
    I --> J["返回菜单"]
```

## 8. 排序的调用顺序

```mermaid
flowchart TD
    A["sort_students"] --> B["qsort"]
    B --> C["compare_score_desc"]
    C --> D{"比较两个成绩"}
    D --> E["高分在前，低分在后"]
    E --> F["排序完成"]
    F --> G["show_students"]
    G --> H["for 遍历"]
    H --> I["print_student"]
    I --> J["返回菜单"]
```

`qsort` 在排序过程中多次回调 `compare_score_desc`。比较函数返回负数、0 或正数，分别表示排序先后关系。

## 9. 保存数据的调用顺序

```mermaid
flowchart TD
    A["选择 7 或 0"] --> B["save_students"]
    B --> C["fopen(student.dat, wb)"]
    C --> D{"打开成功？"}
    D -- 否 --> E["perror 并返回失败"]
    D -- 是 --> F["fwrite 写入全部记录"]
    F --> G{"写入数量正确？"}
    G -- 否 --> H["提示写入失败"]
    G -- 是 --> I["fclose"]
    I --> J{"关闭成功？"}
    J -- 否 --> K["perror 并返回失败"]
    J -- 是 --> L["返回成功"]
```

选择 7 保存成功后继续显示菜单。选择 0 保存成功后还会继续调用 `free_list`，最后正常退出。

## 10. 重新读取数据的调用顺序

1. `main` 选择 8。
2. 调用 `free_list(&list)` 释放原数组。
3. 调用 `init_list(&list)` 恢复空列表状态。
4. 调用 `load_students(&list, DATA_FILE)` 重新读取 `student.dat`。
5. 每条记录通过 `ensure_capacity` 放入动态数组。
6. 输出读取结果并返回菜单。

## 11. 退出流程

```mermaid
flowchart TD
    A["choice == 0"] --> B["save_students"]
    B --> C{"保存成功？"}
    C -- 否 --> D["free_list"]
    D --> E["EXIT_FAILURE"]
    C -- 是 --> F["free_list"]
    F --> G["输出退出提示"]
    G --> H["EXIT_SUCCESS"]
```

退出时先保存数据，再释放动态内存。这样可以保证程序结束后不会遗留动态内存，也不会丢失学生信息。

## 12. 一次完整示例的调用链

假设用户依次输入“1、1001、张三、88.5、7、0”，调用顺序如下：

```text
main
 ├─ init_list
 ├─ load_students
 ├─ print_menu
 ├─ read_int                 // 读取 1
 ├─ add_student
 │   ├─ read_int             // 读取 1001
 │   ├─ find_student
 │   ├─ read_line            // 读取 张三
 │   ├─ read_score           // 读取 88.5
 │   ├─ ensure_capacity
 │   └─ 写入数组
 ├─ print_menu
 ├─ read_int                 // 读取 7
 ├─ save_students
 │   ├─ fopen
 │   ├─ fwrite
 │   └─ fclose
 ├─ print_menu
 ├─ read_int                 // 读取 0
 ├─ save_students
 ├─ free_list
 │   └─ free
 └─ EXIT_SUCCESS
```

这条调用链体现了程序的核心结构：`main` 负责流程控制，业务函数负责具体操作，输入函数负责数据校验，文件函数负责持久化，列表函数负责动态内存管理。
