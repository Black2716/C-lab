# AI_record.md — AI辅助程序开发记录
## 项目：英文文本统计分析系统优化

### 1.初始需求
实现英文文本统计C语言程序。
输入：article.text
输出：文件字符数、单词数量、不同单词数量、出现频率最高10个单词。
原始代码完成基础功能，但大数据规模性能差，需要AI辅助做性能优化。

### 2.原始代码问题定位（AI分析）
1. 文件读取2次，rewind回退文件指针，IO开销翻倍。
2. find_word函数线性遍历数组，查找复杂度O(N)。
3. 冒泡排序O(n²)，大数据量性能差。
4. MAX_WORD_NUM=10000静态数组，存在越界风险。
5. fgetc单字符读取，系统调用频繁。
6. 缺少单词缓冲区溢出保护；无内存释放。

### 3.AI给出优化思路
1. IO优化：只读取一次文件，读取过程同步统计字符；使用fread块缓冲区批量读文件。
2. 查找优化：实现字符串哈希表，链表解决哈希冲突，单词查找平均O(1)。
3. 排序优化：使用标准库qsort快速排序替代冒泡排序。
4. 内存优化：使用malloc动态链表，取消固定数组上限；程序结束释放全部内存。
5. 健壮性优化：增加单词缓冲区溢出保护。

### 4.关键技术点沟通
- Q：C语言没有现成hash库，如何实现哈希？
A：手写简易哈希表，取模映射槽位，链表处理冲突，课程实验不需要第三方uthash库。
- Q：fread块读，怎么处理跨块的单词？
A：块循环解析，单词缓冲区保留未完成单词，跨块自动拼接。
- Q：哈希表如何交给qsort排序？
A：遍历哈希链表，把全部节点指针收集到动态数组，再调用qsort。
- Q：内存泄漏如何避免？
A：程序结束遍历哈希表每一条链表，逐个free节点，释放指针数组。
